# A little birthday moment

A reusable Chinese birthday greeting template for GitHub Pages.

- Dreamy purple starfield, glowing hand-drawn cake, warm wishes
- The page opens quietly with a countdown; the birthday party button starts 26 rising balloons and 140 falling ribbons/confetti
- Clicking the cake shows a separate wish received animation without replaying the party
- Edit `DEFAULT_CONFIG` in `index.html` for a name, date and message; the default stays generic
- Mobile-first layout with reduced-motion support

Deploy: Settings → Pages → Deploy from a branch → main → /(root).
